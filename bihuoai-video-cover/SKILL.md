# 必火AI视频封面

**文字是主角，产品与关系传达信息，人物提供信任背书。**

默认只交付 1 张。平台生图通过 `agent-bihuoai` MCP 调用；本 Skill 负责输入整理、模型选择、提示词、降级规则和成品质检。

## 全流程授权衔接

由 `bihuoai-video-pipeline` 调用且用户本次已授权封面制作时，首张图的模型、素材、张数与费用影响以预检说明告知后直接执行，不重复确认。没有要求封面时不自动增加该付费阶段；重画和第二版本不因自动模式而获授权，既有明确授权的有限降级链按下方规则处理。会话工具未加载时可用全流程 Skill 的客户端托管 MCP 恢复方式，不读取凭证。单独调用时沿用下方规则。

## 连接和付费规则

- 使用客户端已完成 OAuth 授权的 `agent-bihuoai` MCP，不处理任何平台凭证。
- MCP 不可用时按 `https://agent.bihuoai.com/oauth/mcp-install` 引导连接，不回退到直连接口。
- 真正创建前调用 `list_ai_media_models` 核对当前账号可用模型、参数和费用。
- 用户明确要求“生成、制作、修改封面”可视为本次首张图的生成意图，但调用会扣费的工具前仍要清楚说明模型、张数和费用影响并取得确认。
- 每次重画、第二版本或模型降级都可能再次扣费；只有符合下述自动降级规则且用户已经一次性确认该链路时才继续。

## 输入和素材

- 最少输入一句标题。要求真人身份或真实场景时，还必须有对应人物图或视频底图。
- 默认路径是 **人物或视频底图 + 提示词**，不要求成品封面参考，也不自动附加历史封面。
- 参考封面仅在用户明确说参考、复刻、沿用、模仿或点名某个案例时加入。
- 可选素材包括官方 Logo、吉祥物、产品截图、实测场景和关系步骤；没有官方素材时不臆造 Logo。
- 最多 3 张参考图。优先保留人物底图、官方 Logo 和最关键的产品截图。
- 本地图片先用 `bihuoai-material-upload` 得到公网 URL，再放入 `referImages`。
- 可以读取私有用户配置中的 `cover_` 字段作为候选底图和历史案例：macOS / Linux 为 `~/.bihuoai-skills/bihuoai-digital-human/BIHUOAI_USER_CONFIG.md`，Windows 为 `%USERPROFILE%\.bihuoai-skills\bihuoai-digital-human\BIHUOAI_USER_CONFIG.md`。不得输出其中的数字人资源信息。

## 版式和质量规则

需要结构化输入时读取 [封面输入规格](references/cover-spec.md)，生成提示词时必须读取 [固定母提示词](references/master-prompt.md)。

- `hero`：大标题 + 一个产品或结果 + 真人。
- `comparison`：两个对象围绕 VS，不无依据判定胜负。
- `workflow`：箭头连接来源、执行和输出，不用平均摆 Logo 代替关系。
- `tutorial`：只表达用户提供的步骤。
- `opinion`：一句判断 + 一个概念视觉 + 真人。
- 默认 9:16，关键标题、Logo、关系和完整人脸放在纵向 12.5% 至 87.5% 的中央安全区。
- 主标题逐字准确、中文粗大高对比；不新增口号、数字、署名、水印或发布标签。
- 保留参考人物身份、脸型、五官、发型、眼镜、服饰和真人质感；无明确要求不换脸、不卡通化。
- 默认白或浅灰底、黑色粗字、少量红色强调，保持简洁、专业、商业科技感。

## 模型顺序

1. `gpt-image-2.5-sunburst`
2. `gpt-image-2.5-flare`
3. `qwen-image-3.0-pro`，默认使用 2K

规则：

- 先用 `list_ai_media_models` 确认模型真实可用；不存在或未开放时跳过。
- 用户点名模型做对比时只创建该模型的一次任务，不先调用其他模型。
- Sunburst 和 Flare 不擅自增加只属于千问的 `imageSize` 字段；千问默认传 2K。
- 只有当前模型明确失败，或成功状态却没有图片 URL，且原因不是余额、额度、权限、授权、内容审核或参数错误时，才尝试下一模型。
- 轮询超时、网络状态不明或任务仍在处理中时不得降级，避免重复扣费。
- 已经生成图片但视觉质量不理想，不属于失败；先交付并说明问题，用户要求修改后再创建新任务。

## 生成流程

1. 整理标题、副标题、图片角色、关系、清理项和明确要求。副标题不补造，事实和数字只来自用户输入。
2. 默认只选择人物或视频底图。只有用户明确要求参考某张历史封面时才加入它，并且只参考布局和配色。
3. 按母提示词填入有效字段，删除空字段，确保图片编号与 `referImages` 的实际顺序一致，总提示词不超过平台限制。
4. 调用 `list_ai_media_models`，展示选定模型、比例、分辨率、参考图和费用预检。
5. 用户确认后调用 `create_ai_media`，保存任务 ID。
6. 用 `get_ai_media_status` 查询，间隔不少于 15 秒。超时或断线继续查询原任务，不重复创建。
7. 成功后获取图片 URL。若环境支持保存本地文件，可保存到用户指定路径；不要覆盖旧图，修改版本使用 v2、v3。
8. 必须查看实际成品，再核对标题、人物、Logo、关系、比例和安全区。不能只凭提示词宣称通过。

## 交付检查

- 标题逐字准确，英文品牌大小写正确，无漏字、乱码、重复或擅加内容。
- 人物身份、脸、眼镜、服装、手和嘴没有明显失真。
- Logo 结构、颜色和比例正确；产品截图的关键内容没有被改写。
- 标题最醒目，人物不挤压文字，关系和箭头一眼能懂。
- 图片接近 9:16，关键内容位于中央安全区。
- 无虚构数据、错品牌、无关装饰或水印。

## 边界

- 只制作封面，不自动修改口播稿、创建数字人、剪辑或发布。
- 不自动使用私人历史封面，也不把旧案例的文字、Logo、数据或结论带入新图。
- 不因状态未知而创建第二个任务。
