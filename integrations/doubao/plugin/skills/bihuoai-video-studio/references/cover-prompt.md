# 封面提示词参考

按本次有效输入组织下列信息。空项省略；文字逐字保留；图片编号必须与实际 `referImages` 顺序一致。总长度遵守当前工具限制。

- 准确文字：主标题、副标题及必须呈现的其他文字。允许合理分行，不增加口号、数字、署名、重复标题或发布标签。
- 图像角色：人物底图、官方 Logo、产品截图、用户明确指定的风格参考。没有提供的素材不要臆造。
- 信息关系：仅表达用户给出的对比、流程、步骤或观点，不能用装饰性图标冒充事实。
- 画布：默认 9:16；主要信息位于纵向 12.5% 至 87.5% 的中央区域，左右保留边距，不画裁切线。
- 人物：保留身份、脸型、五官、发型、眼镜和真人摄影质感；按用户授权范围缩放、移动、改善曝光和背景融合。无明确要求不换脸、不改服饰和手势。
- 品牌：保留提供的官方标识结构、颜色、比例及截图关键内容，不能自行重绘相似标识作为官方素材。
- 设计：标题优先，人物约占四分之一至三分之一；简洁背景、高对比大字、明确层级，用户指定色优先。
- 清理项：仅删除用户明确要求移除的物体；保留用户指定不可改的部分。
- 安全：不通过“去水印”指令删除权利标识；不承诺模型一定不改变人脸或文字，最终以实际成品质检为准。

修改版本继续使用已授权原图及当前封面，列明具体修改项；每次再次生成先确认费用。成功出图后检查实际图片，而不是根据提示词推断结果。
