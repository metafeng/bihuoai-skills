# 链接提取

1. 从用户提供的分享文本取得真实来源 URL，保留原始来源。只处理用户指定的链接。
2. 按当前 `extract_content` 定义检查支持范围及费用，必要时先确认，再提取内容。
3. 核验正文非空，保留平台原始转写、标题和来源，不把空返回或任务受理当成提取成功。
4. 需要校正时按标题、全文、上下文和语法处理同音词、明显重复和标点。普通品牌名称可作为识别对象，不能据此宣称属于其他办公平台。
5. 年份、数字、人物关系、否定、因果及立场不得擅改。两个候选都合理时保留原词并标记待核实。
6. 交付“原始版”和“校正版”，明确关键修改；用户只要原文时不要额外润色。

提取结果只是素材，不直接作为已确认的最终口播稿。检查来源权益；不能以提取方式帮助盗版分发或移除权利标识。状态未知先查原任务，不重复扣费。
