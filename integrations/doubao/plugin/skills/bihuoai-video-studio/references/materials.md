# 素材处理

只读取用户明确指定的文件或附件；不得扫描目录、批量读取未点名文件或上传整个文件夹。素材上传及公开 URL 可能使文件离开用户设备，操作前说明文件和目标并确认。

## 优先使用已有素材

- 用户已提供平台可访问的媒体 URL 时，核验格式、用途和权益，直接用于对应工具。
- 用户选择平台素材库时，按当前定义查询 `list_media_assets`；不得跨账号复用私有素材。
- 需要保存素材库或创建分组时，明确说明写入范围并确认，再按定义调用 `save_media_asset` 或 `create_media_group`。

## 本地文件或豆包附件

- 只使用当前豆包公开支持的附件传递能力与服务端工具处理文件；文件摘要、上传、回调及注册交给受支持的上传链路。
- `prepare_file_upload` 若只返回上传准备信息，不代表文件已上传。没有真实文件字节传递能力时，不能仅凭这个返回声称上传成功。
- 有受支持的文件和上传工具时，先验证指定路径或附件是普通文件，获取 `fileName`、字节 `size`、`md5`，原样传给当前 `prepare_file_upload`。不能编造摘要，不能把内容摘要代替 MD5。
- 返回 `exists: true` 且有有效 `url` 时复用已存在素材，避免重复传输。否则仅由受支持的上传能力使用返回的一次性 `upload` 信息发送指定文件字节，并完成平台实际要求的回调或登记。
- 上传票据过期时按工具定义重新准备；不要拼接一次性字段，不把票据、签名或临时上传地址写入聊天、任务记录或公开报告。HTTP 上传成功但平台登记失败仍算失败，不能自动重复上传。
- 如果当前连接没有支持的附件上传能力，说明当前限制，引导用户在必火AI平台素材页上传指定文件，再继续选择平台素材或使用上传后返回的 URL。
- 不提供运行本地脚本、安装依赖、手工填写密钥或粘贴临时上传凭据的替代方案。

必须取得平台确认后的真实素材 URL 才算完成。不要保存或展示一次性上传信息。内容审核未通过的素材不得用于后续生成；网络成功不能代替平台登记成功。

图片、音频、视频及平台实际支持的文档均按此处理。查询参数和检查文件不是上传授权；用户明确要求“上传这个文件”已经授权指定文件到必火AI的本次上传，不重复索要同一动作的确认。素材库保存或新建分组另行按本次写入范围处理。若豆包没有字节上传工具，保留人工素材页上传的替代流程并明确标记，不能宣称自动上传能力已经实现。
