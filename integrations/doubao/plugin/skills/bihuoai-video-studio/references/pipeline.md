# 全流程与恢复

按用户实际目标组织阶段；只要其中一阶段时不要强行执行全流程。

1. 记录输入和需求范围。分享链接先提取，本地素材先按素材处理规则准备；未经确认的参考资料不直接作为最终口播稿。
2. 读取文案创作说明，交付并确认标题、正文和描述。已明确确认的用户稿件直接沿用。
3. 读取数字人说明及 TTS 规则，查询当前账号资源，审核并确认生成参数及费用后创建任务。
4. 保存数字人任务 ID，查询原任务到成功，取得真实视频 URL。
5. 用户需要封面或剪辑时，分别读取对应说明、审核、确认费用、创建并查询，保留已有作品。
6. 用户需要保存草稿或发布时，读取发布说明。平台写入和正式发布分别确认，正式发布前核对最终内容和目标。
7. 各阶段完成、失败、待人工确认、被审核拒绝或用户停止时更新任务记录。

## 状态记录

在当前豆包任务上下文中记录阶段、原任务 ID、参数摘要、输出 URL、确认范围和最终状态；环境支持安全保存时按用户指定位置保存。不要要求用户准备本机配置文件或安装技能。

建议包含文案确认状态、数字人任务、封面任务、剪辑任务、草稿 ID、各账号发布提交及最终回执。不能保存凭据、一次性上传信息或把私有素材提交公共位置。

恢复时先读取已有记录并查原任务，不能把断线、轮询超时或状态未知当作重建理由。保留成功阶段，从失败或待确认阶段继续。收费任务明确失败后重新创建也需用户确认。

## 完成判定

数字人、封面和剪辑均需真实成功状态、可用结果及审核状态；发布以外部平台或桌面客户端最终回执为准。任何阶段缺少实证时说明未完成的部分，不把流程计划当作已执行结果。
