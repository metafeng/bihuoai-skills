# 视频发布

默认先预检，不默认保存平台草稿，也不默认正式发布。

1. 按 `get_usage_guide` 及当前实际工具查询绑定平台、账号及发布记录。没有对应工具或权限时停止并说明，不能猜账号 ID 或平台编码。
2. 核对最终标题、正文描述、真实视频 URL、封面 URL、目标账号、时间与时区；审核内容及所用形象、声音和作品的权益。
3. 只保存草稿时，展示拟保存内容，明确说明这是平台写入并取得确认，再调用 `create_pub_article`。
4. 正式或定时发布前，再次展示最终稿件、平台账号和时间，取得与该发布动作对应的独立确认。此前的文案、视频、封面或剪辑确认均不包含发布。
5. 按当前 `submit_publication` Schema 一次提交一个账号；多账号逐一记录真实提交结果，不自动增加平台、账号或改变发布时间。
6. 保存稿件 ID 和提交记录。超时或状态未知时，先查原发布记录或桌面客户端回执，不能盲目重发。
7. 只有外部平台回执明确成功，才报告“已发布成功”。保存草稿、提交到桌面客户端或发起分发请求分别报告，不互相替代。

当前发布能力可能依赖用户已登录的必火AI桌面客户端和目标平台账号；按实际服务返回检查。没有真实回执时交付“已提交，最终状态待确认”。重试、删除、更换目标或覆盖均需新的明确确认。
