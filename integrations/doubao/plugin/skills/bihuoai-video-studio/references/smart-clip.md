# 智能剪辑

接收已有主视频或数字人成片，不在剪辑阶段重新创建数字人。

1. 核验可用的 `mainVideoUrl`，不要把作品 ID 当作视频 URL。
2. 调用 `list_clip_templates`，展示当前账号模板的名称及 `templateCode`，由用户选择。
3. 按模板和当前工具 Schema 准备必要的文稿、声音、形象及素材，不传未声明字段。
4. 审核输入视频、文案、音频及素材权益；展示模板、主视频、模式、补充素材和费用，确认后调用 `create_clip_task`。
5. 当前 Schema 支持时默认 `mode=auto`。编辑模式进入待确认后，通过已声明的打开页面能力引导用户检查，不能代替用户确认。
6. 保存任务 ID，调用 `get_clip_task_status` 查询原任务；成功且有成片 URL、内容审核通过并检查实际结果后交付。
7. 失败时保留原任务 ID 和错误。超时、断线、状态未知时继续查询，不重复创建。

剪辑完成不自动发布。不擅自跨账号使用模板或生成素材，不通过删除审核信息或更换工具绕过内容限制。
