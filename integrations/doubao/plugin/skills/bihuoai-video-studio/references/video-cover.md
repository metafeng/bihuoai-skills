# 视频封面

只制作用户要求的封面，不自动改稿、生成数字人、剪辑或发布。

1. 收集逐字标题、可选副标题、人物或视频底图及必要品牌素材。有人物身份要求时必须有对应底图。最多使用当前工具支持的参考图数量，不臆造官方 Logo。
2. 默认使用人物/视频底图加提示词。只有用户明确要求参考某张历史封面时才加入它，且只参考布局和配色。
3. 按封面提示词参考组织描述；不添加未提供的数字、结论、口号、署名或产品关系。
4. 调用 `list_ai_media_models` 查询当前账号可用模型与参数，按用户要求和实际能力选择，不硬编码未开放模型。
5. 审核输入文字和参考图的内容及使用权益。展示模型、参考图、比例、张数、分辨率及费用，确认后调用 `create_ai_media`。
6. 保存任务 ID，用 `get_ai_media_status` 查询原任务。成功且有图片 URL 后检查真实图片、文字、人物、品牌素材、比例及审核状态。
7. 交付真实结果及检查限制。不能查看实际图片时明确说明尚未完成视觉质检，不声称通过。

默认竖版 9:16，关键标题、完整人脸、品牌及关系放在画面中间 3:4 区域，上下留白。采用简洁、高对比的商业设计，用户明确配色优先。

审核拒绝、余额不足、权限错误、参数错误、任务仍在处理、网络状态未知均不能通过换模型重试。明确失败后的重试或重画需重新说明费用并取得确认，不用新任务掩盖原结果。
