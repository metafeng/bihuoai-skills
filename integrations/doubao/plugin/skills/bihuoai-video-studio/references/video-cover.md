# 视频封面

只制作用户要求的封面，不自动改稿、生成数字人、剪辑或发布。

1. 收集逐字标题、可选副标题、人物或视频底图及必要品牌素材。有人物身份要求时必须有对应底图。最多使用当前工具支持的参考图数量，不臆造官方 Logo。
2. 默认使用人物/视频底图加提示词。只有用户明确要求参考某张历史封面时才加入它，且只参考布局和配色。
3. 按封面提示词参考组织描述；不添加未提供的数字、结论、口号、署名或产品关系。
4. 调用 `list_ai_media_models` 查询当前账号可用模型与参数，按用户要求和实际能力选择，不硬编码未开放模型。
5. 审核输入文字和参考图的内容及使用权益。展示模型、参考图、比例、张数、分辨率及费用，确认后调用 `create_ai_media`。
6. 保存任务 ID，用 `get_ai_media_status` 查询原任务。成功且有图片 URL 后检查真实图片、文字、人物、品牌素材、比例及审核状态。
7. 交付真实结果及检查限制。不能查看实际图片时明确说明尚未完成视觉质检，不声称通过。

默认竖版 9:16，关键标题、完整人脸、品牌及关系放在画面中间 3:4 区域，上下留白。采用简洁、高对比的商业设计，用户明确配色优先。

## 原封面能力的完整处理

- 默认只生成 1 张。按封面输入规格归一化为 hero、comparison、workflow、tutorial 或 opinion；突出 1–2 个词但保留标题全部文字。图片编号匹配本次实际参考图顺序。通常最多 3 张参考图，同时受当前 Schema 限制。
- 保留人物的身份、脸型、五官、发型、眼镜、服装和真实摄影质感。用户明确提供的 cover_ 偏好可作候选，不自动读取私人历史封面。风格参考仅用于布局和配色，不能带入旧图文字、Logo 和结论。
- 原先首选顺序是 `gpt-image-2.5-sunburst`、`gpt-image-2.5-flare`、`qwen-image-3.0-pro`；必须先查当前模型列表，缺失或未开放就跳过。用户指定模型只创建该模型的一次任务。千问仅在 Schema 支持时默认 2K；不向其他模型传只属于千问的 `imageSize`。
- 只有模型明确失败或成功状态没有图片 URL，且与授权、余额、额度、权限、内容审核和参数错误无关，才可考虑下一个实际可用模型。必须已向用户说明降级顺序、最大任务数和费用范围并取得该链路确认；否则先询问。状态未知、处理中、轮询超时不降级。真实成图但质量不理想不算失败，按用户改稿要求另行确认费用。
- 交付时逐字检查标题、英文品牌大小写、漏字、乱码、重复；检查人物五官、手、嘴、服装及 Logo 结构、颜色、比例，确认关系一眼能懂。不添加虚构数据、装饰水印和署名。
- 支持保存时使用用户指定位置；修改稿用 v2、v3，保留旧图，不覆盖原图。没有下载能力时交付真实图片链接并说明保存限制。

审核拒绝、余额不足、权限错误、参数错误、任务仍在处理、网络状态未知均不能通过换模型重试。明确失败后的重试按上述已确认降级范围处理；范围外重试和重画需重新说明费用并取得确认，不用新任务掩盖原结果。
